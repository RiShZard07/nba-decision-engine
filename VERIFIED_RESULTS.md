# Verified results

Every number below comes from synthetic data generated by `nba/simulate.py` with the default seed (7). They describe the behavior of the code, not any real business. Reproduce them with the commands shown; small differences are possible across library versions because the gradient boosting models and the bootstrap use library random streams.

Environment used for this record: Linux, 2 cores, Python 3.13, numpy 2.5.3, pandas 3.0.5, scikit-learn 1.9.1, scipy 1.18.1, pytest 9.2.0. CI runs the same commands on Python 3.12.

## Commands

```
pip install -r requirements.txt
python -m pytest -q
python -m nba demo --check
python -m nba recommend --customer-id 42
```

## Test suite

`python -m pytest -q`: 63 passed in about 14 seconds. No network access is needed; every fixture is generated in process from seeds.

Coverage by area: simulator determinism and propensity bookkeeping (8), uplift learners recovering known effects plus Qini and AUUC including a hand-computed example (12), bandits beating uniform random with sublinear regret on a well specified environment (12), policy constraints (10), offline evaluation including the logging policy self-check, DR beating IPS across seeds and interval coverage (7), explanations (4), experiment runner and gate logic (4), CLI (6).
